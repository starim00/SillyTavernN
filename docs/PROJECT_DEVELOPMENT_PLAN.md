## 实现目录

| 目录                     | 职责                                  |
| ------------------------ | ------------------------------------- |
| `apps/web`               | React/Vite 工作区与浏览器兼容运行时   |
| `apps/server`            | Fastify API、生成协调、导入与工具路由 |
| `apps/legacy-host`       | 可选的固定版本插件宿主                |
| `packages/contracts`     | 共享类型与 Schema                     |
| `packages/core`          | 提示词、导入导出、世界书与正则处理    |
| `packages/storage`       | SQLite、迁移、事务、工具授权和审计    |
| `packages/providers`     | 模型协议适配与流事件                  |
| `packages/extension-sdk` | 原生扩展运行合同                      |
| `packages/legacy-compat` | 固定版本元数据、资源锁和兼容宿主合同  |

## 变更要求

功能变更应明确入口、持久化归属、兼容影响与可观察的验收行为。优先维护导入角色卡、打开对话、应用预设、连接模型、生成与恢复这条主流程。

新协议、扩展 API 或额外产品流程需要独立定义范围和验收条件，不以完整复制上游功能为默认目标。兼容数据中出现的字段不自动成为用户界面功能。

实现与设计不一致时，应定位具体入口及合同，修正错误描述或按已授权需求修复实现。涉及应用行为的变更按根目录约定检查、提交、推送并同步 NAS；文档整理不代表应用已重新构建或部署。
